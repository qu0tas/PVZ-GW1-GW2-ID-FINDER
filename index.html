ID_ Hash Finder

Вставь целевой хеш (например 081816D8, с 0x или без) — страница подберёт строку вида ID_xxxxxxxx, которая даёт ровно этот хеш. Всё считается локально, в браузере.

Алгоритм: h = 0xFFFFFFFF; for byte c in "ID_" + suffix: h = (h*33 + c) mod 2^32. Поиск ведётся методом "встречного перебора" (meet-in-the-middle): строится прямой словарь хешей для первой половины суффикса и обратный — для второй, затем ищутся совпадения.
